Getting Started

The Order Management System is used to create customer orders, prepare dispatches, manage delivery documents, review daily dispatch activity, and maintain the master data used by the system.

Orders Record customer orders
Dispatches Prepare truck loads
Dispatch Summary Review daily activity
Management Maintain master data

Typical Daily Workflow

1

Create the Order

Open Operations → New Order. Select the customer, add the ordered products, enter the quantities, and save the order.

2

Create a Dispatch

Open the order and select Create Dispatch. Remaining products and quantities are loaded automatically.

3

Confirm Transport Information

Select a company driver and truck, or enter external transport information when required. These details may be added later if they are not yet known.

4

Print the Required Documents

Use the Dispatch, Purchase Request, and Delivery Note pages to review and print the required documents.

5

Review the Daily Dispatch Summary

Open Dispatch Summary and select the required date. The report can be printed, exported to Excel, or downloaded as an image for electronic sharing.

Orders

How do I create an order?

Use Operations → New Order. Choose the province or territory to help locate the correct customer, then add the required products and quantities.

The order serial number and date are generated automatically but may be changed when necessary.

How do I find an existing order?

Open the Orders page and begin typing in the search field. Results update automatically.

You can search using details such as the order number, customer, customer ID, or territory.

What do the order statuses mean?

Draft means the order is still being prepared.

Confirmed means the order has been approved for normal processing.

Cancelled means the order should no longer be dispatched.

Dispatches

Do I need to re-enter the products from the order?

No. When a new dispatch is created from an order, the system automatically loads the products that still remain to be dispatched.

If the truck is carrying only part of the order, reduce the quantity in the Dispatch Now column.

What happens when an order needs several trucks?

Create the first dispatch and enter the quantities carried by that truck.

When another dispatch is created for the same order, the system shows the quantities already dispatched and automatically calculates what remains.

What is the difference between Order Date and Dispatch Date?

Order Date records when the customer's order was created.

Dispatch Date records the date assigned to the specific truck or dispatch.

Dispatch Date is independent and can be edited. For example, an order may be created on Monday while one truck leaves on Tuesday and another leaves on Wednesday.

What if the truck or driver is not known yet?

Driver and truck information can be left blank initially. Edit the dispatch later when the information becomes available.

What if transportation is external?

Leave the company driver or truck field empty and enter the external driver name or external truck plate instead.

External transport details apply only to that dispatch and do not need to be added to the company's permanent driver or truck lists.

Dispatch Summary

Which date does the Dispatch Summary use?

The Daily Dispatch Summary uses Dispatch Date, not Order Date.

This means a truck appears in the report for the day assigned to its dispatch.

How can I share the Dispatch Summary?

The Dispatch Summary provides three options:

Print Summary for paper copies.

Export Excel for spreadsheet sharing or further analysis.

Download Image creates a PNG version that can be attached to applications such as WhatsApp.

Management

What is the Management section used for?

Management contains the permanent information used throughout the OMS, including Products, Drivers, Trucks, Customers / Distributors, and Territories.

What happens when I deactivate something?

Deactivation prevents inactive master data from being selected for normal new transactions while preserving older records that already used it.

This is preferable to deleting historical information.

How are Driver IDs created?

When a new driver is added, the system automatically suggests the next Driver ID, such as DRV0001.

How are Customer IDs created?

When a new customer is added, the system automatically suggests the next customer ID, such as CUST000001.

Why can't two active customers use the same territory?

The OMS allows only one active distributor for a territory at a time.

If a different customer must become active for the same territory, deactivate the currently active customer first.

Searching and Filtering

Most major list pages support live searching. Begin typing in the Search field and matching records will appear automatically.

Filters such as Active / Inactive also update the list immediately on supported pages.

Use Clear to remove the current search and filters.

Common Problems

A product, driver, truck, or customer is missing from a selection list.

Check the appropriate Management page and make sure the record is marked Active.

I changed a dispatch but the printed document still shows old information.

Save the dispatch first, then reopen or refresh the printable document before printing again.

Search results do not seem to update.

Refresh the page and try again. If the problem continues, report it to the system administrator.

Need More Help?

If the system displays an unexpected error or a business transaction cannot be completed using the instructions above, contact your OMS system administrator or supervisor.

When reporting a problem, include the Order Number or Dispatch Number when applicable and describe what you were trying to do when the issue occurred.
